# C4 impacts on terrestrial water storage

This repository contains the MATLAB scripts used to generate the main and supplementary figures for the manuscript.

## Software

- MATLAB R2022b or later
- Mapping Toolbox
- Statistics and Machine Learning Toolbox
- Image Processing Toolbox

## Main figures

- `Mar_2026_Figure1_TWSd_during_droughts.m` - Figure 1
- `Mar_Plot_Figure2_TWS_C4.m` - Figure 2
- `Mar_Plot_Figure2_TWS_C4_All_cover.m` - Figure 2 analysis including all land-cover classes
- `Mar_Plot_Figure3_TWS_change.m` - Figure 3

## Supplementary figures

- `Mar_2026_FigureS_TWS_during_droughts.m` - TWS changes during droughts
- `Mar_2026_FigureS_TWSd_during_droughts_irr.m` - irrigation sensitivity analysis
- `Mar_2026_FigureS_drought_impact_TWS.m` - drought impacts on TWS
- `Mar_2026_FigureS_drought_impact_TWS_vpd.m` - VPD sensitivity analysis
- `Mar_Figure_SI_Drought_impacts_map.m` - spatial patterns of drought impacts
- `Mar_Figure_SI_ESM_c4_changes.m` - modelled C4 changes
- `Mar_Plot_FigureS_TWS_drought_no_irrigation.m` - analysis excluding irrigated areas
- `Mar_Plot_FigureS_drought_on_dTWS.m` - drought impacts on TWS changes
- `Mar_Plot_FigureS_drought_zscore.m` - standardized drought analysis
- `Mar_Plot_FigureS_importance_LAI.m` - LAI sensitivity analysis
- `Mar_Plot_FigureS_number_of_valid.m` - number of valid observations
- `Mar_plot_figure3_resistaance.m` - physiological response analysis

## Usage

Place the required input files in the paths specified at the beginning of each MATLAB script, and run the corresponding script in MATLAB.

The large input datasets are not included in this repository. Data sources and availability are described in the manuscript.
